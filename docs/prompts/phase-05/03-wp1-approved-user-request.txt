## 1. 项目背景与不可变约束

项目名称：戏境 AI。

当前项目包含：

- 8个 HTML 页面，以原生 HTML、CSS、JavaScript 为前端基础。
- FastAPI 后端。
- 京剧私有知识库 RAG。
- SQLite 元数据管理。
- Qdrant 向量检索。
- BGE-small-zh-v1.5 中文 Embedding。
- DeepSeek 模型调用。
- 多 Agent 工作流：任务规划、RAG文化研究、角色设计、文化审校、人工确认。
- Q版与写实两种角色风格。
- 两个已经完成真实 Neural4D 生成并通过约定技术验收的 GLB 模型。
- Web 3D Viewer，支持至少260°旋转、缩放、重置、加载状态及错误恢复。

重要历史状态：

- Phase 1、Phase 2、Phase 3 已完成各自约定的验收。
- Phase 4 已在两模型交付范围内验收通过。
- Phase 5 检查点 A 已批准。
- 当前正式实施阶段为 Phase 5 WP1。

Phase 5 检查点 A 的方案与审查文档位于项目 `docs/reports/` 和 `docs/prompts/phase-05/` 相关目录。实际执行前必须检查真实文件，不能只依赖上述描述。

### Neural4D 强制约束

全项目真实建模提交历史：

- 已使用2次。
- 剩余1次，但用户明确决定不执行第三次建模。
- 创建功能必须保持关闭。

绝对禁止：

- 调用 Neural4D 创建接口。
- 提交新的建模任务。
- 修改全局建模次数。
- 通过测试绕过创建锁。
- 重新生成已有模型。

两个现有真实 GLB 必须保持不变。

### 其他约束

- 保留原有8页网站及文化内容。
- 不引入 React、Vue、Next.js 等前端框架。
- 不进行大规模重构。
- 不删除用户现有文件或历史记录。
- 不输出、复制或提交任何 API Key。
- 不调用付费 API。
- 不安装、升级或删除依赖，除非另获明确授权。
- 不合并 main。
- 不推送远端。
- 不进入后续工作包。

## 4. 第三步：真实梳理端到端用户流程

本次必须从实际代码出发，确认每一步到底发生了什么。

需要检查：

- 页面入口。
- 前端事件处理。
- API 请求。
- 后端路由。
- 服务层。
- 数据存储。
- Agent 交接。
- 角色数据结构。
- 人工确认机制。
- 资产关联。
- 3D Viewer。

### 4.1 京剧文化问答流程

梳理：

用户提出问题
→ 前端提交
→ 后端接收
→ RAG检索
→ 模型生成或资料不足判断
→ 引用验证
→ 前端显示答案与来源。

逐项确认：

- 问题是否真正发送到后端。
- 检索是否使用真实知识库。
- 引用是否指向实际来源。
- 资料不足时是否正确处理。
- API 失败时是否显示真实错误状态。
- 是否存在仅供演示的静态答案。

不得仅根据界面上的按钮或文案认定功能已接入。

### 4.2 多 Agent 角色设计流程

梳理：

用户需求
→ 任务规划
→ RAG文化研究
→ 角色JSON设计
→ 文化审校
→ 人工确认
→ 角色JSON输出。

逐项确认：

- 各步骤的实际调用关系。
- 输入输出的数据结构。
- 状态和错误如何传递。
- 文化审校是否真正执行。
- 用户确认是否确实影响流程。
- 角色JSON是否能够保存、查看或下载。
- 失败后能否继续查看已产生的结果。

特别注意：

必须区分实时 Agent 执行、持久化历史记录与静态演示回放。

不能将历史记录冒充当前实时执行，也不能伪造 Agent 调用日志。

### 4.3 两个真实3D模型的展示流程

检查：

- 两个真实模型的实际资产路径。
- 资产数据库中的关联记录。
- 角色与风格标识。
- 前端模型选择方式。
- GLB 加载路径。
- 材质和纹理引用。
- Loading、Ready、Error 状态。
- 加载失败后的恢复行为。
- 旋转、缩放和重置事件。

必须明确：

**两个真实 GLB 是已生成的展示资产，不代表每次用户提交角色需求都会自动触发新的 Neural4D 建模。**

当前不得调用建模 API。

如果新角色创作与已有模型展示是两个独立步骤，文档必须如实说明。

### 4.4 个人模式与企业模式

检查现有入口和真实功能。

明确区分：

- 京剧文化传播与问答。
- AI Agent 角色创作。
- 已有3D资产展示。
- 企业角色设计需求入口。
- 尚未实现的商业工作流。

如果没有真实企业客户案例、实际企业项目或完整的企业交付流程，必须明确标注。

不得伪造客户、案例、订单、收入或企业部署记录。
