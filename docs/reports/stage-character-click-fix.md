# 数字戏台人物点击修复

日期：2026-10-30；基线`69dedd5ae9313c7ffd93152108ffc7c1cbb64507`，分支`feature/phase5-competition-delivery`，开始时工作区干净。本轮仅前端交互修复与证据，不重新建模。

## 问题与实际复现

用户报告“3D模型互动只能互动舞台，人物模型不能点击”。确认两类问题：

1. 左侧人物卡片只重复选择和展示已默认选中的同一个人物，没有镜头靠近或可见反馈，因此点击像未生效。
2. 远景人物很窄，画布点选必须命中实际三角面；旧逻辑在手指微动改变相机后才判断释放位置，并固定7px阈值。既有桌面测试最多尝试7个偏移，任一成功便通过；手机测试没有实际单指点选，覆盖不够。

本轮真实旧版诊断中，杜丽娘正中/部分上下位置能点中，横向偏15px不能；所以没有把问题描述成“射线完全失效”。旧版诊断第二个模型等待超时，随后独立重测发现用户8000服务已停止，保留该中断，不能把它计为通过或认定为模型损坏。

## 最小改动

- `digital-stage.js`：明确点击左侧人物卡片时，Ready且资源可用才选择并靠近；初载、分类自动选择、重试不自动聚焦，Error不执行聚焦。
- `stage-viewer.js`：保留真实几何命中及舞台遮挡判断；按下时记录目标，允许小幅手指抖动，超过阈值的完整拖动轨迹和多指手势取消点选；加载、隐藏面板时清除旧候选。
- 增加跟随人物位置的**“姓名 · 近看”**按钮，方便鼠标、触摸和键盘定位。它是明确的可访问选择入口，**不会计入几何射线命中次数**。
- 聚焦后显示“近看某人物”，重置回戏台全景；原旋转/缩放仍可用，人物保持静态，不增加表演动作。
- 独立CSS、页面提示及模块版本号同步更新，使刷新后读取新脚本。
- `digital_stage_frontend_test.mjs`增加真实意图测试：卡片选择/聚焦、自动操作不聚焦、错误态不聚焦和0请求。
