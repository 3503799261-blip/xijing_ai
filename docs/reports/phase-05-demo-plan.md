## 5. 免费备用路线

| 故障 | 可用备用 | 必须保留的说明 |
|---|---|---|
| DeepSeek无网/超时/预算不足 | 停止发送，读取历史任务/JSON/来源和本地模型 | “历史真实记录，当前在线调用不可用”，不把缓存结果伪装新回答 |
| 后端没启动/端口占用 | 按运行指南确认应用/单worker，或展示已录真实操作 | 不删除锁、自动安装或杀未知进程，不称备用视频为当前运行 |
| BGE/索引缺失 | Viewer/文化页面独立展示；资料来源与历史检索报告可读 | 不退化为随机Embedding/硬编码回答 |
| 写实GLB加载失败 | 只重载原ID，核对Hash和资源；失败持续则展示历史截图/报告 | 标当前加载失败，不重新建模，不消耗第3次 |
| 资产不在克隆环境 | 明确缺少受控私有资产；用合法Duck验证Viewer技术 | Duck不是京剧模型、不是供应商成果，不能替代成品演示 |
| 新Agent暂停 | 显示真实原因，保留当前任务，再转历史成功流程 | 新任务不改状态、不自动重试，旧成功不是新执行结果 |
| 真机不可用/内部页拒绝跨LAN | 桌面Chrome+CDP分别展示 | “模拟通过、实体未测”，不解除内部限制 |
