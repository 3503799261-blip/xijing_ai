## 你只需要点击这里

1. 保持当前项目`D:\京剧\京剧`在VS Code中打开，点击左侧 **“运行和调试”**（三角形带小虫图标）。
2. 顶部选择 **“戏境 AI：一键运行”**，点击旁边的 **绿色三角形**；以后直接点击即可，也可以按F5。

服务就绪后会自动打开：[AI戏韵工坊](http://127.0.0.1:8000/about.html#ai-workshop)。不是编辑器右上角针对某个文件的“运行Python文件”按钮，不需要自己输入命令。

启动时终端会显示“正在启动，请等待本地模型加载”。本次带调试器实际启动约 **80.703秒**，不要反复点击；耗时会随机器状态变化。看到“服务已就绪”后才打开浏览器，不用手动猜等待时间。

**停止：点击调试工具栏的红色方块，或按Shift+F5。** 实测停止后8000端口已释放。服务与启动器在同一进程，无额外后台Uvicorn子服务。

## 出错时怎么看

| 提示 | 处理方式 |
|---|---|
| 8000端口占用 | 若原项目正在运行，先停止原调试会话；不要重复启动或结束不认识的进程。启动器不会强杀进程、换端口。 |
| 缺少依赖、配置无效 | 在VS Code底部终端查看中文提示；沿用现有`.venv`和仓库外私有配置，不会自动安装或覆盖`.env`。虚拟环境本身缺失时，调试器可能直接提示找不到Python，需恢复原环境。 |
| 缺库、库损坏、模型/Hash异常 | 保留原文件，按已有运行/恢复指南核对备份；不要初始化空库、重建知识库或重新建模来代替恢复。 |
| 有未结束Agent、未知建模任务或预算范围不符 | 预检停止，防止普通启动恢复改写旧记录；先核查原任务/配置，不自动取消、重跑或退还次数。 |
| 浏览器没自动打开 | 服务会保留运行，在终端点击“服务已就绪”后的工坊链接即可。 |

一键启动本身不调用付费AI。你之后主动点击“发送问题”或提交Agent任务，仍可能使用项目原有的付费功能；历史档案和已有GLB查看只读，不重新建模。Neural4D仍已用2/3、余1未使用，第三次取消，创建开关保持关闭。
