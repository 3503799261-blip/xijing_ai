## 最终布局与交互

- **左栏**：概念图及本地待保存预览、Q版/写实风格；角色来源和企业需求、Prompt、上传/合法GLB导入、参数及额度按需折叠。生成按钮仍禁用，明确第三次建模已取消。
- **中栏**：当前真实模型标题、宽幅Viewer、Loading/Ready/Error、拖拽、触摸、缩放、重置及原文件错误恢复。来源与Hash放入详情，减少重复卡片和说明。
- **右栏**：从真实列表动态建立资产库，显示实际登记概念图、名称、风格、已有模型或尚无模型状态；可滚动和手动刷新。缩略图明确标“概念图”，没有冒充模型渲染截图。

桌面使用`250px / 自适应 / 220px`三栏，工作台内容上限1640px；1250px以下收窄侧栏，850px以下资产库移下，手机依次为Viewer、资产库、操作区。三栏只对模型面板生效，其他工坊与文化页面保持现有布局。Viewer从该区原深酒红网格改为暖米白，没有改成黑色科技主题，没有使用参考图的品牌或视觉资产。

入口保持[数字资产与3D工作台](http://127.0.0.1:8000/about.html#ai-workshop-model)，原写实资产深链接继续有效。默认恢复明确选择的已有模型或资产；没有选择时优先读取已有正式模型，不生成新记录。当前角色缺少某风格时保留真实空态，右库可另选其他已有资产。

**现有8000进程不会热加载新后端代码。** 本次保留用户调试会话；查看完整新列表前，请在VS Code点红色停止，再运行“戏境 AI：一键运行”。未重启时新界面会提示重启以载入内部列表，不谎称Q模型不存在。8877仅测试，结束后关闭，不作为产品入口。

真实失败保留：首轮浏览器读取出现`ERR_NO_BUFFER_SPACE`，第二次正常加载；缺失风格测试最初等待过早，修正等待查询完成，不改业务空态；后端首轮沙箱硬链接权限失败，随后一项测试夹具对隔离额度文件的假设不正确，改为文件集合和全部Hash不变检查；前端测试最初遗漏合法schema字段，修复夹具而非放宽验证。

独立复核还修正了跨资产未保存文件残留、等待Viewer组件时选择竞态、模型与概念图版本不对应、内部用途沿用正式角色及返回面板后选择标记失同步问题。真实资产和后端建模逻辑均未为这些UI修复改变。

次级入口首轮4组通过、1组失败：企业导览定位到了折叠表单但未展开，普通用户看不到目标控件。仅在明确点击该入口时展开对应`details`，不修改企业选项或提交表单；复测5组通过，既有导览34项也再次通过。
