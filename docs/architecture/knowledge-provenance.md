## 事实与版本审校

采用了以下处理，避免只凭官方域名便自动判为权威正确：

- 京剧形成采用“清代、多剧种交流融合”的事实层面，没有将徽班进京等同于剧种在单日形成，也没有选定唯一形成年份。前期查到不同官方文章的形成时段表述有差异，细化年代仍需专业复核。
- 行当是角色与表演体系，流派是艺术传承风格；资料中的细分类别按各页面适用范围使用，不强行拼成唯一分类表。
- 脸谱颜色保留主色、副色、使用部位和具体人物语境。黑色的不同用途以及红色主副色差别都在语料中明确，避免“颜色=全体人物固定性格”的绝对规则。
- 包拯月牙、阴阳两界的说明属于舞台寓意。京剧《霸王别姬》《三岔口》《穆桂英挂帅》的叙述属于该院介绍的舞台剧情，不作为历史人物真实经历的独立证明。
- 《穆桂英挂帅》只采用剧目简介所指1959年京剧改编背景和情节，不合并教材唱段、豫剧或其他改编版本的全部情节。
- 《梅(兰芳)派》是2008年资料；没有将其中当时的在世、活跃人物描述当作2026年的现状。
- 未将 UNESCO 京剧页面入库：前期直接访问出现人机验证，正文与具体许可没有完成可复核采集。仍可保留为后续人工核查方向。

## 评价候选与人工复核

`knowledge/evaluation/questions.json` 当前有20题：6基础、5行当人物、4脸谱服饰、3跨来源、2资料不足。18个支持题的预期来源和 section ID 均指向当前文件；两个不足题没有虚构正确文献。跨来源题为 opera-q16、opera-q17、opera-q18。

标注状态统一为 `assistant_source_checked_candidate`。这些是助手对照来源提出的预期事实与证据候选，尚不是人工 gold 标注。可以用于研发自检、问题定位和候选证据命中率；不能据此声称“人工标注 Recall@5”或“人工核查正确率”。普通 LLM 与 RAG 的对照结果也应分开保存，未执行结果不计入报告。

用户／文化专业人员复核时，应逐题对照链接，确认 expected_facts 与证据是否支持、同义答案范围是否合理、版本差异是否需要追加范围。记录真实审核者、日期、结论、修正原因及关联数据版本，再将状态改为真实完成的人工复核状态。不能仅因脚本检查 JSON 成功便将其改成 human_reviewed。
