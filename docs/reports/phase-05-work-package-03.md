## 4. 必要的错误恢复修复

既有问答/Agent本来就保留失败输入、停止等待、允许手动重试并沿用幂等标识；本包保留逻辑，只补就近历史/导览入口和清晰文案，不调整全部业务重试策略。

实际修复：

1. **链接资产首次读取失败无法按钮恢复**：原实现先清空待恢复ID，后续刷新只读模型列表/额度。现在保留原ID，显式刷新重新GET同一资产；不登记替代资产、不自动重试。已有图片/Ready GLB在元数据失联时保留并标为已加载快照，不冒称服务在线。
2. **风格读取失败被说成未生成**：读取中/失败显示待核实或状态未知，只有成功返回缺失记录才显示无该风格；空任务ID不发查询，也不留下假加载。用户可手动重读。
3. **旧首次建模文案失真**：改为两个历史成果、第三次用户取消、创建关闭；费用60积分明确是原验收归档，不是新报价/实时账户余额。实际次数仍从台账读，缺数据不硬填2/3。

GLB加载/错误/原文件重载直接复用原Viewer。错误恢复实测先返回浏览器模拟503，随后用户手动重载**同一真实模型文件**进入Ready；未修改GLB或调用Neural4D。

最终收尾还修正了检查中退出的提示：立即显示“已停止本轮检查”，解除等待；迟到响应不能覆盖退出状态。该分支已在原导览专项中加强验证，34项再次通过。
